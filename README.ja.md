# CodexQuotaGauge

言語： [English](README.md) | [繁體中文](README.zh-TW.md) | **日本語** | [한국어](README.ko.md)

Windows 11 のタスクバー付近に表示する使用量ウィジェットです。Codex の残り使用枠を大きく読みやすい数字で表示します。Claude の使用量取得機能もコード内に残していますが、初期状態では無効です。必要になったらメニューから有効化できます。

## プレビュー

Codex が現在週次の使用量データだけを返す場合、ウィジェットは自動的に週次のみのコンパクト表示になります。

![Codex コンパクト表示](assets/codex-compact.svg)

Claude と Codex の両方を有効にし、5 時間枠と週次枠の両方が取得できる場合：

![Claude と Codex のフル表示](assets/dual-dashboard.svg)

## 機能

- Codex の週次残り使用量をパーセントで表示します。
- OpenAI が Codex の 5 時間枠データを返さない場合、Codex の 5 時間欄を自動的に非表示にします。
- Claude の使用量監視機能は保持されていますが、初期状態では無効です。
- 右クリックメニューから更新、詳細表示、Claude のオン／オフ、終了ができます。
- Windows 起動時に自動起動します。

## インストール

1. このリポジトリをダウンロードまたは clone します。
2. `Install.bat` をダブルクリックします。
3. ウィジェットが Windows の通知領域付近に表示されます。

インストール先：

```text
%LOCALAPPDATA%\CodexQuotaGauge\app
```

## アンインストール

`Uninstall.bat` をダブルクリックします。

アンインストーラーは常駐プロセスを停止し、スタートアップショートカットとローカル状態データを削除します。

```text
%LOCALAPPDATA%\CodexQuotaGauge
```

## 必要環境

- Windows 11
- Codex Desktop がインストール済みでログイン済みであること
- Claude の使用量監視を使う場合のみ、Claude Desktop がインストール済みでログイン済みであること

## 使い方

- パネルを右クリックしてメニューを開きます。
- `立即更新` を選ぶと使用量データを再取得します。
- `開啟詳細資訊` を選ぶとリセット時刻を表示します。
- パネルをダブルクリックして詳細ウィンドウを開けます。

## プライバシー

CodexQuotaGauge は、ローカルでログイン済みの Codex／Claude Desktop セッションから使用量情報を読み取ります。トークンをこのリポジトリ、状態ファイル、通知、ウィジェット画面に書き出すことはありません。
